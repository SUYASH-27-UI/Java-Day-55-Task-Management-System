# Java Day 55 - Task Management System

## Description
A Java console application for organizing tasks and tracking their progress using object-oriented programming.

## Features
- Add new tasks
- Assign task priorities
- View all tasks
- Search tasks using Task ID
- Update task status
- Delete tasks
- Save task records permanently

## Files
- `Main.java` - Main Java program
- `tasks.txt` - Task records

## Requirements
- Java JDK

## How to Compile
```bash
javac Main.java
```

## How to Run
```bash
java Main
```

## Concepts Used
- Classes and Objects
- Constructors
- ArrayList
- CRUD Operations
- File Handling
- Searching and Updating Records
